# Legacy Documentation

This folder captures lessons learned from three prior incomplete rewrites (2013-2018) of **Castle of the Winds**, a classic Windows 3.1 roguelike RPG by Rick Saada.

Each attempt made significant progress but stalled due to architectural or ecosystem issues. These documents preserve the design knowledge, implementation details, and hard-won lessons so the current rewrite can build on what worked and avoid what didn't.

## Contents

- [castle-of-the-winds.md](castle-of-the-winds.md) — The original game: mechanics, systems, and scope
- [cotwjs.md](cotwjs.md) — First rewrite (2013): TypeScript + jQuery
- [cotwmtor.md](cotwmtor.md) — Second rewrite (2015): Meteor + React + Redux
- [cotwelm.md](cotwelm.md) — Third rewrite (2016-2018): Elm 0.18
- [game-systems.md](game-systems.md) — System scope: what was implemented vs what remains
- [assets.md](assets.md) — Original ripped sprite assets and their locations
