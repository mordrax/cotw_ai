# Original Game Assets

Sprites ripped from the original Windows 3.1 Castle of the Winds game. Sourced from the mordrax/CoTWjs repository under `assets/resources/`.

## Sprite Sheets

| File | Contents | Tile Size |
|------|----------|-----------|
| `tiles.png` | Dungeon/outdoor floor, wall, door, stairs, decoration tiles | 32x32 |
| `monsters.png` | All monster sprites | 32x32 |
| `items.png` | Weapons, armor, potions, scrolls, rings, amulets, gold, containers | 32x32 |
| `spells.png` | Spell icons for spell book UI | 32x32 |
| `spell_effects.png` | Spell effect animations | 32x32 |

## Additional Assets

- **`buildings/`** — Town building sprites at various sizes (1x through 5x)
- **`splash/`** — Title screens and menu backgrounds

## Format

All assets are PNG format.

## Source

Original repository: **mordrax/CoTWjs**, directory `assets/resources/`

## Usage in Current Project

These assets can be reused directly in the new project via the `public/assets/` directory.
